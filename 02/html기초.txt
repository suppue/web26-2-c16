태그 

텍스트		:	<h1>	</h1>
				<p>	</p>
다른 태그인 경우	:	<div>
					<h1>		</h1>
					<p>		<p>
				</div>
내용을 입력하지	:	<div>	<div>
않은 경우 			<audio>	</audio>
				<video>	</video>

태그와 요소
	HTML 표기법과  XHTML 표기법
		HTML	:	<요소 이름>만으로 요소를 생성 / 내용을 가질 수 있는 태그의 시작 태그로 오해할 수 있음
			<img>
			<br>
			<hr>

		XHTML	: 	명확하게 내용을 가질 수 없는 태그라고 표기할 수 있음
			<img />
			<br />
			<hr />


속성 : 태그에 추가 정보를 부여
	1. <h1 title = "header">HelloHTML5</h1>
